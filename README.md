# Burnice — Pixel Walk / Training garden v18

ซอร์สเกมเวอร์ชันล่าสุดสำหรับเปิดในเครื่องและพัฒนาต่อด้วย Codex

## การพัฒนาแบบส่วนตัว

เจ้าของต้องการพัฒนาเกมโดยยังไม่เปิดให้คนทั่วไปเห็น ระบบเผยแพร่ GitHub Pages อัตโนมัติถูกปิดแล้ว
การ commit/push ใช้เก็บโค้ดใน GitHub เท่านั้น ต้องตั้ง Repository เป็น **Private** ใน Settings ด้วย
หากต้องการเปิดเว็บเกมต่อสาธารณะในอนาคต ให้เจ้าของสั่งเผยแพร่ใหม่อย่างชัดเจนก่อน

## ทดสอบบนมือถือแบบส่วนตัวด้วย Codespaces

เปิด `https://codespaces.new/DIw1945/MausChan?ref=master` ด้วยบัญชี GitHub ที่มีสิทธิ์ใน Repo นี้ แล้วกดสร้าง Codespace
GitHub Codespaces มีโควตาฟรีตามบัญชีและอาจมีค่าใช้จ่ายเมื่อใช้เกินโควตา โปรดตรวจหน้าแสดงโควตาและการเรียกเก็บเงินก่อนสร้าง

คอนฟิก `.devcontainer/` จะเปิดเกมที่พอร์ต **4173** ให้เอง ในแท็บ **Ports** ให้ตรวจว่า Visibility เป็น **Private** (ค่าเริ่มต้นของ Codespaces)
แล้วกดเปิดลิงก์พอร์ต4173 ในเบราว์เซอร์มือถือ ต้องล็อกอิน GitHub ด้วยบัญชีที่มีสิทธิ์ก่อน ห้ามเปลี่ยนพอร์ตเป็น Public
เก็บลิงก์นี้ไว้ใช้ทดสอบ เกมเปิดได้เมื่อ Codespace ทำงานอยู่ หากหยุดเพราะไม่ได้ใช้ ให้เปิด Codespace เดิมอีกครั้ง

หลัง Codex commit/push เกมเข้า `master` ตัวรันทดสอบจะดึงโค้ดทุก20วินาที จากนั้นรีเฟรชหน้าเกมเพื่อดูเวอร์ชันใหม่
หากมีการแก้ไฟล์ใน Codespace เอง อยู่คนละสาขา หรือมี commit แยกจาก `master` ระบบจะไม่ทับงานนั้นและอาจต้องอัปเดตเอง
บันทึกการทำงานอยู่ที่ `/tmp/burnice-private-preview.log` หากเปิดเกมไม่ขึ้น
พอร์ตส่วนตัวของ Codespaces แยกจาก GitHub Pages; คง Pages และ workflow เผยแพร่สาธารณะไว้ในสถานะปิด

## เปิดเกมบน Windows

1. แตก ZIP ทั้งหมดก่อน อย่าเปิดไฟล์จากข้างใน ZIP
2. ติดตั้ง Node.js LTS หากยังไม่มี: เปิด PowerShell แล้วรัน `winget install --id OpenJS.NodeJS.LTS`
3. ปิดแล้วเปิด PowerShell ใหม่หลังติดตั้ง
4. ดับเบิลคลิก `start-game.cmd` แล้วเปิด http://127.0.0.1:4173 ในเบราว์เซอร์
5. เปิดหน้าต่างตัวรันค้างไว้ หยุดด้วย Ctrl+C

หรือเปิด Terminal ในโฟลเดอร์นี้แล้วใช้:

~~~powershell
npm.cmd start
~~~

ไม่ต้อง `npm install` และไม่มี build step เกมอยู่ใน `dist/` อยู่แล้ว
บน macOS/Linux ใช้ `npm start` ในโฟลเดอร์นี้

## ปุ่มเล่น

| ปุ่ม | การทำงาน |
| --- | --- |
| WASD / ลูกศร | เดิน 8 ทิศ |
| J / Z / Space | ฟันดาบ |
| กดโจมตีค้าง | ชาร์จ เดินได้พร้อมอนิเมชั่นและออร่าดาบ |
| ปล่อยหลังชาร์จเต็ม | หมุนตัวฟัน |
| E | ดื่ม Nitro-Fuel ถ้ามีไอเท็มและเลือดยังไม่เต็ม |
| Q | วางระเบิดด้านหน้า แล้วถอยให้พ้นวงรัศมี |
| กด WASD / ลูกศรรัว ๆ | สลัดเมือก 12 ครั้ง / Webbed I 28 ครั้ง / Webbed II 44 ครั้งใน 10 วินาที |

เลือดเต็มจะปล่อยคลื่นดาบไฟ มีหุ่นทดสอบดาเมจและหุ่นยิงลงด้านล่างหนึ่งตัว
Nitro-Fuel ตัวอย่างวางใกล้จุดเริ่ม เดินลงซ้ายเล็กน้อยเพื่อเก็บ
มีระเบิดให้เก็บ 3 ลูกใกล้จุดเริ่ม ชนวน 2.2 วินาที ดาเมจ 180 รัศมี 88 px
ระเบิดทำลายหินร้าวก้อนใหญ่เพื่อเปิดทางได้ ดาบและคลื่นไฟทำลายไม่ได้
แรงระเบิดโดนตัวเอง 1 หัวใจ; บนมือถือใช้ปุ่มระเบิดเหนือปุ่ม Nitro-Fuel
ในหน้าเกมมีตัวตรวจ Sprite พร้อมหยุด/เลื่อนเฟรม
แท็บ “ระเบิด / หินแตก” แสดงไอเท็ม ชนวน แรงระเบิด และหินแตกครบ 20 เฟรมใหม่
ดาวน์โหลดชุดภาพเพิ่มได้จาก `dist/assets/bombs-rocks-v9-sprites.zip`

เดินไปทางขวาผ่านช่องพุ่มไม้เพื่อเข้าลานฝึก Slime ที่อยู่ติดลานเดิม
มีจุดเกิด 4 จุด เติม Slime เมื่อมีน้อยกว่าจุดละ 3 ตัว
เขียวธรรมดา / น้ำเงินตัวใหญ่แตกเป็นลูก 4 ตัว (เกินเพดานจุดเกิดได้) / ชมพูตัวเล็กเร็ว
v11 ง้างและพักโจมตีช้าลงราว 20–30% โดยความเร็วเดินคงเดิม
ทุกชนิดโจมตีแล้วสะสมเมือก เมื่อเต็มจะเดินและโจมตีไม่ได้ พร้อมท่าเปื้อนเมือกดิ้นเบา ๆ สีหน้าหยะแหยง 12 เฟรม ที่ 9 fps
กดทิศทางใหม่รัว ๆ 12 ครั้งเพื่อหลุด กดค้างไม่นับรัว; มือถือแตะปุ่มสลัดหรือสลับทิศจอย
ชุด Sprite ปัจจุบัน 40 เฟรมอยู่ใน `dist/assets/slimes-sticky-v11-sprites.zip` พร้อมต้นฉบับและพรอมป์ต์ โดยเก็บชุด v10 ไว้ย้อนหลัง

ลานแมงมุมอยู่ฝั่งซ้าย ตรงข้ามลาน Slime เดินผ่านช่องพุ่มไม้ช่วงกลางได้เลย
มี 4 รัง สูงสุดรังละ 2 ตัว แมงมุมสีม่วงยิงกระสุนใย และสีส้มโจมตีประชิด
แมงมุมทั้งสองชนิดมี Sprite เดินและโจมตีครบ 4 ทิศ ชนิดละ 32 เฟรม
กระสุนใยที่โจมตีโดนสะสม Webbed ครั้งละ 50% เมื่อครบ 100% จะขยับและใช้ไอเท็มไม่ได้
Burnice จะนอนดิ้นติดใยที่พันตัว แขนขาและปาก เป็นลูป 12 เฟรม ที่ 8 fps
ต้องกดทิศทางใหม่รัว ๆ / ปุ่มดิ้น / สลับทิศจอย รวม 28 ครั้งเพื่อหลุด (กดค้างไม่นับ)
ระหว่างติดใยแมงมุมโจมตีต่อได้โดยเลือดไม่ลด แต่สะสมใยขั้นสอง: กระสุน 20% / ประชิด 15% (กระสุนล้วน 5 ครั้ง / ประชิดล้วน 7 ครั้ง) พร้อมช่วงเว้นการสะสม .7 วินาที
เมื่อใยขั้นสองเต็มจะพันแน่นขึ้นและปิดตา เริ่มนับใหม่ 44 ครั้ง ภายใน 10 วินาที การโจมตีซ้ำไม่รีเซ็ตความคืบหน้าหรือเวลา
v14 ท่า Webbed II ดิ้นแรงขึ้นด้วยการเกร็งไหล่ งอตัวและขยับเข่าที่ถูกมัด พร้อมใยพันหนาขึ้น โดยขนาดหัวและจุดวางร่างคงเดิม
หากดิ้นไม่ทันจะ Game Over โดยเลือดคงเดิม อยู่ในท่าติดใยขั้นสองและหายใจเบา ๆ 8 เฟรม ไม่มีท่าหมุนเซ/ล้มแทรก
หลัง Game Over แบบติดใย แมงมุมจะเลิกโจมตี ถอยออกจากร่าง แล้วเดินสุ่มรอบรังต่อโดยเว้นที่รอบตัวผู้เล่น ลาน Slime ก็เดิน/เกิดตามปกติ
หลุดแล้วมีช่วงอมตะ 1.5 วินาที; ปุ่ม Retry หรือ R รีเซ็ตสถานะและเวลา
แพ็กปัจจุบัน 100 เฟรม: `dist/assets/spiders-webbed-v14-sprites.zip` พร้อมต้นฉบับ พรอมป์ต์ เฟรมแยกและ metadata โดยคงแพ็ก v12/v13 ไว้
ชุดเดิมทั้งหมดยังใช้ร่วมกัน รวมปัจจุบัน 388 เฟรม มีแท็บเดิน/โจมตี 4 ทิศของแต่ละชนิด และ Webbed I / II / หมดเวลา ใน Sprite Inspector

v15 เปลี่ยนต้นไม้ทั้ง 9 จุดเป็น Sprite ภาพนิ่ง 4 แบบจาก Image Generation ไม่มีแอนิเมชั่นลม โคนต้นและจุดชนเดิมคงอยู่ พร้อมการบังหน้าหรือหลังตัวละครตามตำแหน่ง
ดูภาพทั้ง 4 แบบในแท็บ “ต้นไม้ภาพนิ่ง” และดาวน์โหลดต้นฉบับ/atlas/เฟรม/พรอมป์ต์ได้จาก `dist/assets/trees-v15-sprites.zip`

## โซน Mummy ด้านบน (v18)

เดินขึ้นเหนือจากลานเดิม ผ่านประตูที่มีป้าย `↑ MUMMY YARD` (หลบต้นไม้บริเวณปากทางไปทางซ้ายเล็กน้อย)
มีจุดเกิด 2 จุด จุดละไม่เกิน 2 ตัว รวมสูงสุด 4 ตัว เกิดทดแทนทุก 6 วินาทีเมื่อมีที่ว่าง
Mummy มี 200 HP เดินช้าและยื่นแขนทั้งสองข้าง ท่าข่วนระยะใกล้ทำดาเมจ 1 หัวใจ
ส่วนท่ายิงสายผ้าพันแผลทำดาเมจ ½ หัวใจ มีสัญลักษณ์เล็กเหนือหัวก่อนโจมตีและหลบกระสุนออกด้านข้างได้
ใช้ดาบ คลื่นไฟ และระเบิดกำจัดได้ รวมระบบดรอป Nitro เดิม

Sprite จาก Image Generation มี 48 เฟรม (เดิน/ข่วน/ยิงผ้า อย่างละ 4 เฟรม × 4 ทิศ)
และสายผ้าอีก 4 เฟรม ดูและเลื่อนเฟรมได้ใน Sprite Inspector และดาวน์โหลดได้จาก
`dist/assets/mummy-v18-sprites.zip` มีต้นฉบับ เฟรมแยก atlas metadata และเครื่องมือตัดภาพครบ
